Les informations essentielles sur le concept Zahrawi Academy.

Nature du site

Zahrawi Academy est un établissement fictif présenté dans un projet de démonstration web. Le site est issu de la maquette Zahrawi Academy fournie pour ce projet.

Contenus illustratifs

Les profils, expériences, témoignages et tarifs sont fictifs. Les photographies illustrent le concept ; elles ne représentent pas des locaux ou une équipe en activité. La localisation « Rabat, Maroc » donne le cadre du concept ; aucune adresse d’accueil n’est proposée.

Pas d’offre commerciale

Aucun achat, inscription scolaire ni réservation de séance réelle ne peut être effectué sur ce site. Les formules affichées ne constituent pas une offre commerciale.

Hébergement

Cette démonstration est hébergée sur GitHub Pages.

Avant une mise en activité réelle

Les informations de l’éditeur, les coordonnées et les contenus devront être remplacés par les données vérifiées du centre avant toute utilisation commerciale.
